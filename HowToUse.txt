AliceInCradle 事件编辑器
V1.2 公测版（2026-01）：时隔两年的大更新！现在会实时编译出事件的哈语言代码，并且对话文本支持两种导出方式了。

欢迎使用本事件编辑器，请按照以下步骤操作：
1. 粗略阅读 localization.md（可以用记事本打开但更推荐用 VS code 等 markdown 预览工具，如果打不开就把后缀名改成 .txt），重点是其中对于 ev 类文件的说明和后面的控制序列。
2. 双击 index.html 打开编辑器。点击左上角的帮助按钮了解基本操作，然后点击左侧的「未分类」，获取一个入口积木，开始编辑事件。
3. 点击左侧的各个类别，从中拖动所需的指令积木，拼接在一起并填写（或从下拉列表选取）必要的参数，得到一个完整的事件。
4. 需要关闭页面时不要忘了点击左上角的「保存工程」，把复制的工程代码（json 格式）粘贴到记事本等处保存好，以便下次继续制作。
5. 若要打开之前的工程，只需把保存好的工程代码粘贴到编辑器右侧的代码区，再点击左上角的「读取工程」就能重建出积木啦。
6. 彻底完工后，请把代码区的哈语言代码（每行为一个指令和若干用空格分隔的参数）全选复制到要运行的 .cmd 文件中（详见后文），就可以在游戏中使用。
7. 如果事件中含有对话或留言板，那么可以在入口积木中勾选「对话单独导出」，此时哈语言代码将不再含有它们的正文，你需要点击左上角的「导出对话」得到单独导出的正文，并粘贴到 localization 中的 ev_*.txt 文件。这种方法更不容易出现 bug，而且还能支持多国语言。
8. 【补充】从下拉列表为积木选取参数时，可能会找不到想要的值（比如 0.29 会有新的音乐），这时可以切换到工程模式，在代码区小心地修改成想要的值，再点击「读取工程」就能让这个值出现在下拉列表末尾了。

运行事件的方法：
从 0.25 开始，游戏的 StreamingAssets 文件夹下有了一个 evt 文件夹。该文件夹下的 .cmd 文件便是我们所说的事件了（注意不是 m2d 文件夹哦）。
.cmd 文件的编码必须是不带 BOM 的 UTF-8，必须使用 Unix 风格的换行（LF、\n），不能是 Windows 风格的回车换行（CRLF、\r\n）。
由于换行符号不能用记事本更改，而记事本新建的文件又会统一用 Windows 风格，只能通过复制现有的 .cmd 文件再重命名来解决，所以推荐用 VS code 这样的第三方文本编辑器而不是记事本。
操作步骤：
1. 打开 StreamingAssets 文件夹下的 _debug.txt，把里面的 reloadmtr、announce、timestamp 这三项后面的数字都改成 1
2. 【补充】localization.md 中提到了 reloadmtr 功能（快捷键 F9）的失效问题和修复方案，但如果你没有 dnSpy 反编译工具或者不理解修复方案，那就算了。
3. 入口积木中有一项「事件 ID」，它指的是 .cmd 文件在 evt 文件夹下的相对路径（用 / 分隔），比如 106 子文件夹下的 31_kodo.cmd 这个事件的 ID 就是 106/31_kodo
4. 事件 ID 在「对话单独导出」的模式下很重要，它直接关系到事件运行过程中能否正确显示出对话和留言板的正文，可不能马虎。
5. 打开游戏，检查 F7 菜单能否正常开启（会有鼠标指针不显示的问题，修复方法请加入本文结尾的群聊获悉，临时解决方案则是先按 ESC 呼出菜单再按 F7）。
6. 在顶部的长条（注意不是长条左边的短条）中输入 evt xxx 再敲回车即可运行事件（xxx 为事件 ID），运行过程中右侧会显示调试界面（其顶部也会显示当前的事件 ID），可以再次按 F7 关闭。
7. 这个长条还可以输入别的指令，比如 map xxx 传送到某地图（m2d 文件夹下的 .tmap 文件名），输入 vp 则可以预览立绘并复制其 PIC 指令用于事件。
8. 如果需要事件由玩家触发，则可以在游戏原有的事件中使用 CHANGE_EVENT2 指令调用你的自定义事件，或者编辑 m2d 文件夹下的 .cmd 文件将自定义事件绑定到地图中的调查点（NPC）。
9. 如果需要修改事件内容，只要编辑事件的 .cmd 文件后保存，再在游戏中重新触发即可。但如果要修改已被单独导出到 txt 文件中的对话，就需要使用 F9 的热刷新功能（前提是已修复）或者重启游戏才能生效了。对于 m2d 文件夹的修改，则是返回标题画面生效。

注意事项：
1. 如果你懂得 HTML5 的知识，可以在编辑器页面按下 Ctrl+Shift+I 打开控制台做更多事情。
2. 并非所有哈语言指令都提供了对应的积木（比如显示或隐藏金币栏），请善用「原生指令」。
3. 「延迟执行」积木并不是什么指令都能往里塞（比如流程控制或者编译结果为多行的指令，观察代码区就能注意到），否则出了 bug 后果自负！
4. 如果觉得以你的显示器分辨率每次打开编辑器都需要重新调节积木区大小很麻烦，可以用记事本等文本编辑器打开 index.html 修改默认值。
5. 使用期间如果遇到任何问题，或者有意见建议想要反馈，欢迎加入 QQ 群 907348590 提交！
